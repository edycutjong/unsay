§3 · How it works

One signed write. One MCP frame.

The clinician's write is HMAC-signed over the raw body. The server appends v3 to a hash chain and fires notifications/resources/updated over Streamable HTTP. The host re-reads and speaks. The private lane never answers a user-scope token — it gets -32002, the same as a URI that doesn't exist.

§7 · Honest by design

What isn’t done.

The repo says what isn't done. No Alexa+ host has been reachable yet, so the fallback is built and exercised. The AWS path is written but never run against a live key, because of an account hold. And Unsay only relays what a clinician wrote.
